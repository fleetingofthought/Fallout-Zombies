# New Vegas Zombies

**New Vegas Zombies** is an ambitious, open-source survival-horror project and fork of [NVForever](https://github.com/LootJunkieAzza/NVForever), reimagining *Fallout: New Vegas* as a massive, seamless, round-based Zombies experience.

Inspired by *Call of Duty Zombies*, the project combines classic Zombies mechanics—rounds, perks, wall buys, Mystery Boxes, and weapon upgrades—with Fallout's RPG systems, exploration, and persistent save functionality.

**The goal:** Preserve the charm of classic Fallout while transforming its engine and content into an entirely new survival-horror experience.
